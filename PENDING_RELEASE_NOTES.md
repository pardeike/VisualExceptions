Adds support for RimWorld 1.7 and Harmony 3.

The exceptions tab is now a regular bottom-bar button that appears only while there is something to report. It no longer conflicts with other mods that change the bottom bar.

Exceptions from background threads are recorded safely.

Mods that use Harmony 3 inner patches are now listed when they are involved in an exception.

The website link in the mod menu works on RimWorld 1.7.

A damaged settings file now falls back to the default settings instead of disabling the mod.
